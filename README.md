# 📧 Emailbuch

Eine einfache Desktop-Anwendung in Java zur Verwaltung von Kontakten – speichert Namen und E-Mail-Adressen.

## ✨ Funktionen

- 📥 Hinzufügen neuer Kontakte (Name + E-Mail)
- 📜 Anzeigen aller gespeicherten Kontakte
- ❌ Löschen von Kontakten
- 🔍 Suchen von Kontakten nach Namen oder E-Mail

## 🚀 Installation und Ausführung

1. Klone das Repository:
   ```bash
   git clone https://github.com/patodemjan/Email---book.git

    Öffne das Projekt in deiner bevorzugten IDE (z. B. Eclipse oder IntelliJ IDEA).

    Starte die Main.java-Klasse, die die main-Methode enthält, um die Anwendung auszuführen.

🔧 Verwendete Technologien

    💻 Java 17

    🖼️ Java Swing (GUI)

    🔗 OOP (Objektorientierte Programmierung)

    🧑‍💻 Eclipse IDE (oder eine andere bevorzugte IDE)

📁 Projektstruktur

src/
├── Main.java           # Hauptklasse, um die Anwendung zu starten
├── Contact.java        # Klasse zur Repräsentation eines Kontakts
├── EmailBook.java      # Klasse zur Verwaltung der Kontaktliste
